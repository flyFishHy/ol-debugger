# Changelog

## 0.1.0

- Added the public `createDebugger()` API, an embeddable Lit panel and project-owned Shadow DOM UI components.
- Added OpenLayers map observation, normalized snapshots, eight built-in diagnostics, issue lifecycle management and local JSON report generation.
- Added a Vite library build and a basic OpenLayers demo.
- Web Awesome is intentionally not included; controls and panel styling are implemented in this package.
